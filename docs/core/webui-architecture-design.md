## 一、核心定位

WebUI 是**原则五（统一可观测）的图形化证明**——不是监控面板，不是控制面板。

每个面板回答一个架构问题：
- 事件管线：原则五是否被遵守？（有无裸 `console.log` 逃逸）
- 治理仪表盘：治理流在审视什么？（审计报告、修宪版本流、合规违规）
- 任务树：规划-执行流的非对称均衡是否生效？
- 确认门：交互层的确认锚定是否到位？（L2/L3 阻断 + 触发来源）
- API 用量：技能-工具流的可追溯性是否完整？

**底线**：WebUI 不创造新状态，只暴露已有状态。所有数据来自 `PipelineObserver.emit()`。

**角色分离**：

- **IDE 面板不暴露全量事件**（宪法 §二十）：默认仅通知 + 任务切片，`--verbose` 可控

| **任务树** | 规划-执行层 | `TaskBoard.getAllNodes()` | TaskNode 拓扑 + 状态 + **锁定宪法版本号** | — |

| **Trace 详情** | 规划-执行 + 技能-工具 | Span 展开 | LLM 调用链、跨 Agent Span、成本归因 | — |

## 四、关键设计原则

### 1. 只读快照原则（宪法 §二十）
- WebUI 只消费 `PipelineObserver` 事件流，不直接查引擎状态
- 写操作经 `/api/execute` 转发，**经 `ConfirmGate` 拦截**
- 配置快照只读，编辑走 CLI

### 2. 确认门分级视觉化
| 等级 | 展示 | 行为 |
|:----:|------|------|
| **L3** 不可逆 | 全局置顶横幅，红色，强制聚焦 | 显示触发来源，必须确认 |
| **L2** 高成本可逆 | 确认门弹窗，黄色 | 阻塞操作 |
| **L1** 低成本可逆 | IDE 面板底部提示 | 可一键放行 |
| **L0** 完全可逆 | 通知时间线 FYI | 不弹窗 |

### 3. 事件分级
- `CRITICAL` → 画布金色脉冲 + 侧边栏🟡/🔴 + 确认门
- `HIGH` → 通知时间线 WARNING
- `NORMAL` → 事件管线常规流
- 记忆层内部事件（`Pending→Active`）默认 `NORMAL`，仅状态流转推送，避免高频写入淹没管线

### 4. 自审视与 solo-fight 可视化
- 事件管线：显示 `self-exam.phase0` → `phase5` 完整链路
- Agent 森林：🔍 审视态 / 🛫 飞行态
- API 用量：单独列出"自审视消耗"和"solo-fight 消耗"，与正常任务对比
- 治理仪表盘：自审视报告（AuditReport）、发现矩阵、91.7% 准确度

### 5. Agent 森林卡片设计
- **缩略态**（~120px）：图标 + 名称 + 状态色条 + 当前任务单行，横向滚动
- **展开态**（~320px）：运行时长、资源占用、最近 3 条日志、查看 Trace
- 触发：Click 展开，可同时展开多个。非 Hover。

## 一、核心模型

市面工具以 **Trace** 为中心（一次 LLM 调用的完整链路）。Cortex 的对等概念是 **Mission**（一次任务执行 = 一次自审视 / 一次修复 / 一次调度）。

```
Mission = { nodes: TaskNode[], events: PipelineEvent[], stats: { tokens, cost, latency } }
```

**设计原则**：一个 Mission 一条 Trace。点击节点展开，看内部 LLM 调用链和成本。

## 五、设计约束

1. **双面板不变**。不引入第三个面板。治理/配置/用量塞入已有分区。
2. **画布 = 系统视角**（架构师/调试者）。IDE 面板 = 任务视角（开发者）。
3. **IDE 面板不暴露全量事件**。仅通知 + 当前任务切片。
4. **配置快照只读**。配置编辑不在此 WebUI 范围内（走 CLI 或 config 文件）。
5. **不引入新包**。所有代码在 `packages/tui/src/web/` 下。
6. **代码编辑器为独立视图**。不挤入双面板。通过顶部 Tab 切换：观测 / 编辑。

## 六、代码编辑器（独立视图）

独立于双面板的简洁编辑器，通过顶部切换进入。

```
┌─ Tab: [观测] [编辑] ──────────────────────────────────────┐
│                                                            │
│  ┌─ 文件树 ──────┬── 编辑区 ──────────────────────────┐  │
│  │ src/            │  1 │ // Cortex engine core       │  │
│  │   core/         │  2 │ import { bootstrap } ...    │  │
│  │   agents/       │  3 │                             │  │
│  │ packages/       │  4 │ export function main() {   │  │
│  │   engine/  ●    │  5 │   // active edit            │  │
│  │     bootstrap/  │  6 │ }                           │  │
│  └────────────────┴────────────────────────────────────┘  │
│                                                            │
│  ┌─ Diff 栏（Agent 修改前后对比）────────────────────┐  │
│  │ - const old = foo();                               │  │
│  │ + const updated = bar();                           │  │
│  └─────────────────────────────────────────────────────┘  │
└────────────────────────────────────────────────────────────┘
```

### 功能
- 文件树：只读浏览项目结构。当前活跃 Agent 正在修改的文件高亮标记。
- 编辑区：轻量级代码高亮（CodeMirror 6 或 Monaco 最小包）。支持保存触发。
- Diff 栏：Agent 修改前后对比。agent 执行 `edit_file` 后自动推送到 Diff 栏。
- 不替代 IDE：无扩展、无终端、无调试器。只是 Cortex 的"手术观察窗"。

### 数据源
- 文件树 → `GET /api/files`（WSGateway 新增端点，读项目目录结构）
- 文件内容 → `GET /api/files?path=...`
- Diff → `TuiEventBus` 的 `diff_view` 事件 或 `edit_file` tool result
- 保存 → `POST /api/files?path=...`（仅允许写入 Agent 工作目录）
