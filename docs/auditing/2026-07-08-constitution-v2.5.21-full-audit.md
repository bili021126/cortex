## 第二部分：新增治理缺口与条款矛盾

### 🔴 发现 1（P1）：修宪提案管线合规性违规——AM-2026-0612-001 状态字段非法且宪法内容被部分预执行

**依据**：
- 宪法 §2 原则七子约束5：「修宪提案作为灰色议题——由凝光审计合规性，监理追踪执行，开拓者最终裁决」
- 宪法 §2 原则七子约束1：「修改必须显式引用目标宪法条款。提案须声明修改哪一条款、为何修改、修改后的文本」
- 宪法 §2 原则七子约束3：「最小改动——仅修改必须改的那一行/段」
- AmendmentStatus 类型定义：合法值为 "pending_judgment" | "applied" | "superseded" | "rejected"

**事实**：
1. AM-2026-0612-001.json 的 `status` 字段值为 `"proposed"`——该值不在 AmendmentStatus 类型定义中
2. 宪法 v2.5.21 文件内容已被部分修改以匹配 AM-2026-0612-001 的提议（§1 从「11 种 Agent」改为「13 种 Agent」，§5 标题从「11 种执行单元」改为「13 种执行单元」），但该提案状态为 "proposed" 而非 "applied"，表明未经过完整的修宪流程（未获开拓者裁决）
3. 同一提案的其他修复内容（不可变语义定义、昔涟角色声明、Core-1 过渡方案、TTL 豁免）未被应用——形成选择性执行

**影响**：
- 宪法内容在未获开拓者裁决前被修改，违反原则七子约束5的裁决流程
- 状态字段 "proposed" 不属于 AmendmentStatus 合法值，违反治理数据契约
- 选择性应用提案内容破坏了修宪提案的原子性——应全有或全无

**严重等级**：🔴 高（P1）

### 🟡 发现 2（P2）：2026-07-07 审计承诺的修宪提案未归档

**依据**：
- 2026-07-07 审计报告声明：「已生成对应修宪提案：AM-2026-0707-001、AM-2026-0707-002」
- 宪法 §10 审计闭环条款要求审计发现须对应可追踪的修宪提案

**事实**：
- `docs/amendments/` 目录下不存在 AM-2026-0707-001.json 或 AM-2026-0707-002.json
- 审计报告声明了提案已生成，但实际未写入任何文件

**影响**：
- 审计闭环断裂——审计发现 A 和 C 没有对应的可追踪提案
- 后续审计人员无法判断这两个发现是已修复、被驳回还是从未被处理

**严重等级**：🟡 中（P2）

### 🟡 发现 3（P2）：版本头版本号逻辑矛盾

**依据**：
- 宪法版本头声明：`**版本**：v2.5.22 → v2.5.21`
- 版本演进链从 v2.5.14 → v2.5.11（箭头方向可疑）→ ... → v2.5.21
- §15 修正记录表最后一个条目为 `v2.5.20 → v2.5.21`

**事实**：
1. 「v2.5.22 → v2.5.21」的箭头方向表示 v2.5.22 是当前版本，v2.5.21 是前一个版本——但文件内容实际是 v2.5.21
2. 版本演进链中「v2.5.14 → v2.5.11」箭头方向反向（倒退版本号）
3. 版本头声明的「v2.5.22」在任何修正记录中均无对应条目

**影响**：
- 版本号混乱导致治理追溯困难——后人无法确定当前宪法的确切版本
- 版本头与 §15 修正记录表不一致

**严重等级**：🟡 中（P2）

### 🟡 发现 4（P2）：昔涟角色宪法引用但未定义（与 2026-07-07 审计发现 A 同源但不同维度）

**依据**：
- 宪法 §10.8 定义「皇后（昔涟）」辅政职责
- 宪法 §10.6 中书省映射包含「昔涟+MetaAgent」
- 宪法 §5.1 Agent 类型表中无昔涟条目
- 宪法 §2 子约束5 引用「监理」角色也未定义

**事实**：
昔涟在宪法中被引用为治理角色（皇后/辅政/评判），但：
1. 不在 §5.1 Agent 类型表中定义
2. 没有独立的职责范围、权限边界或调用通道声明
3. 存档版本（v2.5.16 备份）§10.8 明确标注「不入 Agent 注册表」，但当前 §10.8 无此声明

**影响**：
- 宪法条款引用未定义的治理角色，造成引用断裂
- 「监理」和「昔涟」两个角色均引用但未定义——治理角色体系存在系统性的定义缺失

**严重等级**：🟡 中（P2）

### 🟢 发现 5（P3）：§15 修正记录表缺少 v2.5.22 条目

**依据**：
- §15 修正记录表最后一个条目为 `v2.5.20 → v2.5.21`
- AM-2026-0612-001 目标版本为 v2.5.22
- §15 未包含任何 v2.5.21 → v2.5.22 的修正条目

**事实**：
无论 AM-2026-0612-001 是否应被应用，v2.5.22 作为版本头中声明的「下一个版本」在修正记录表中无对应条目。修正记录表与版本头之间的版本号链断裂。

**影响等级**：🟢 低（P3）

### 🟢 发现 6（P3）：webui/constitution_proposal.json 数据残留未清理

**依据**：
- AM-2026-0612-001 明确指出 webui/constitution_proposal.json 应标记为 superseded 或归档
- AM-2026-0612-001 已 supersede AM-2026-0611-001（该文件对应 constitution_proposal.json）

**事实**：
文件 webui/constitution_proposal.json 仍存在于 webui 目录中，未被标记为 superseded 或归档。该文件版本为 v2.5.15，包含 11 项修复，其中 10 项已被后续修正覆盖。残留文件可能误导后续审计人员。

**影响等级**：🟢 低（P3）
