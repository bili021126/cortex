# Cortex 产品化市场调研报告

> 日期：2026-06-28  
> 目的：为 Cortex 从"治理框架"向"个人 AI 开发工作台"的产品化转型提供竞争格局分析

---

## 一、市场全景

AI 编程工具市场在 2025-2026 年经历了剧烈分化，形成了三个清晰的赛道：

| 赛道 | 代表产品 | 核心价值 | 用户量级 |
|------|---------|---------|:--------:|
| **AI IDE** | Cursor、Windsurf | 编辑器内 AI 辅助 | 千万级 |
| **终端 Agent** | Claude Code、Aider、Cline | CLI 原生，自主编辑 | 百万级 |
| **全自主工程师** | Devin | 云沙箱全自主开发 | 万级 |

Cortex 不属于以上任何一个赛道。它的定位是 **第四赛道：个人 AI 开发工作台**——在终端 Agent 的自主能力之上，叠加 Agent 治理、结构化记忆、统一可观测性和分级护栏。

## 三、竞争空白分析

### 3.1 无人同时覆盖四维度

七个竞品中，没有任何一个同时满足 Agent 治理 + 跨会话记忆 + 统一观测 + 分级护栏。最接近的是 **Claude Code**，它有三个维度的雏形，但：
- 记忆系统仅靠 `CLAUDE.md` 文件，无结构化检索
- 观测仅靠 `--verbose` 终端日志，无可视化面板
- Agent 治理仅有 hooks 机制，无多 Agent 调度/注册体系

### 3.2 个人开发者是被忽视的市场

- **Cursor/Copilot** 的治理/观测功能锁在 Enterprise 层级，个人用户不可用
- **Devin** 的全自主模式面向团队，个人用户无力承担 $500/月
- **LangSmith** 是云平台，个人开发者自建 Agent 不想把数据送出本地

**空白**：一个面向个人开发者的、本地的、完整的 Agent 工作台——能调度多个 Agent、能记住跨会话的上下文、能在面板上看到系统在做什么、能在危险操作前拦住你。

### 3.3 Cortex 的不可替代性

Cortex 有三个竞品无法短期复制的壁垒：

1. **多 Agent 治理**：14 种正式 Agent + TaskBoard 拓扑排序 + AgentPool 实例池。竞品都是单 Agent 模式。
2. **宪法级护栏**：七原则硬边界 + ConfirmGate L0-L3 + 自动修宪闭环。竞品最多到 hooks/手动确认。
3. **自审视机制**：Agent 审视自身代码，7 阶段闭环，91.7% 准确度。所有竞品均无此能力。

```
         Agent 治理 →
  ┌──────────────────────────────┐
```

## 五、产品化路径建议

基于竞品调研，Cortex 的产品化应分三步：

### Phase 1：补齐"个人可用"的基础体验

| 优先级 | 事项 | 对标 |
|:------:|------|------|
| P0 | WebUI 布局定型——不再变动 | Cursor 的空间记忆原则 |
| P0 | CLI 交互流畅——单命令启动、自动连接 | Claude Code 的终端体验 |
| P1 | 上下文可视化——"当前 Agent 知道什么"面板 | Windsurf 的 @mention 上下文 |
| P1 | 确认门不回退——L3 阻断后必须手动确认，不可被代码绕过 | Claude Code 的三级权限 |

### Phase 2：建立"Cortex 独有"的能力

| 优先级 | 事项 | 差异化 |
|:------:|------|--------|
| P0 | 跨会话记忆检索——从 MemoryStore 中找回之前的上下文 | 竞品均无 |
| P1 | 多 Agent 协作可视化——画布上看 14 个 Agent 的实时状态 | 竞品单 Agent |
| P1 | 自审视报告面板——治理仪表盘显示审计/修宪/Gap | 竞品均无 |
| P2 | 提示词配方库——可保存、可组合、可版本的提示词模板 | 参考 Dify/Coze |

### Phase 3：从"能用"到"好用"

| 优先级 | 事项 |
|:------:|------|
| P1 | 快捷键唤醒 + 全局命令面板 |
| P2 | IDE 插件（VS Code / Qoder 深度集成） |
| P2 | 桌面端（Tauri 壳 + Live2D 昔涟） |
| P3 | 社区模板市场（Agent 配方、提示词配方） |

## 六、风险评估

| 风险 | 级别 | 缓解 |
|------|:----:|------|
| **API 成本不可控** | 🔴 | 自审视和 solo-fight 是烧钱实验，需成本归因面板精确追踪 |
| **用户门槛极高** | 🟡 | 26 包 monorepo + 14 Agent + 宪法体系，非技术用户无法自建。可接受——目标用户是技术个人 |
| **竞品追赶** | 🟡 | Claude Code 一旦补齐记忆+观测，最接近 Cortex。但多 Agent 治理和宪法护栏是其架构级壁垒 |
| **维护负担** | 🟡 | 4800+ 测试 + 四层 CI 已有防御。但 26 包的接口漂移需持续关注 |

## 七、结论

**Cortex 在一个被忽视的市场上拥有结构性的竞争优势。** 

主流 AI 编程工具分为两派——"极简 Agent"（Aider/Cline，无治理无记忆）和"企业全家桶"（Cursor Enterprise/Copilot Biz，个人不可用）。Cortex 恰好占据了中间地带：**个人可用的、本地的、完整的 Agent 工作台**。

产品化的核心不是"追上竞品"——是"把你在架构层已经解决的东西，让用户界面也能感受到"。七面板已经在跑，宪法已经追上了项目状态，Mock 阶段验证了管线。下一步：定型界面、闭环流程、让护栏可感但不打扰。
