## 一、三层架构

```
┌─────────────────────────────────────────────────────┐
│  中间瞬态层 — 事件驱动生命周期                       │
│  TaskBoard / 审查列表 / 圆桌面板 / 修宪diff          │
│  浏览预览窗 / 任务卡片 / 裁决结果                    │
│  → 产生即出现，结束即消失                            │
├─────────────────────────────────────────────────────┤
│  昔涟管家层 — 唯一持久的交互锚点                     │
│  对话流（所有交互锚点）                              │
│  调度心跳（甘雨 / Scheduler 信号）                  │
│  通知铃（四通道物理路由小红点）                      │
│  ButlerAgent 路由                                   │
├─────────────────────────────────────────────────────┤
│  代码编辑器层 — 纯净编码体验                        │
│  独立 Monaco Editor 实例                             │
│  不与 AI 组件混排                                    │
└─────────────────────────────────────────────────────┘
```

## 二、画布式交互范式

唯一持久保留三项：
- 昔涟对话流（所有交互锚点）
- 状态指示（甘雨 / Scheduler 心跳信号）
- 通知铃（四通道物理路由小红点）

其余全部瞬态——事件驱动生命周期管理。

本质：交互形态与宪法架构同构——五路监督不霸占视野、圆桌不常驻、仲裁结果不滞留。

## 三、Monaco Editor 选型

Cortex 桌面端代码编辑器使用 Monaco Editor。保持编辑器纯净性，不集成任何 AI 辅助组件。
