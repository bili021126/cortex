### 超时性质判定

```
超时发生在：自检 Agent 执行 ReAct 循环验证的过程中
  └─ Agent 需要多次迭代 (64次上限) 来遍历各个审查方向
  └─ 每次迭代调用 LLM + 工具 → 累积耗时
  └─ 300s 壁钟限制 → iteration 18-19 被截断
  └─ 超时后优雅捕获 partial output → 非崩溃

受影响的是：验证 Agent 的"执行预算"
未受影响的是：核心链路（编译/类型/barrel/数据层/CI）
```
