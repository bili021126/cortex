| `schema.ts` | 常量 re-export 桥（从 `@cortex/config` 导入） |

### 3.2 委托关系

```
memory-store.MemoryStore.write(input)
    → embedding 生成
    → SHA256 去重（_tryDedup）
    → 维度校验（EMBEDDING_DIM = 384）
    → this._backend.write(input)  ← 委托 @cortex/memory
    → BM25 索引更新
    → 向量去重（_tryVectorDedup）
    → 超限自动归档（_autoArchiveIfOverflow）

memory-store.MemoryStore.read(query, mode)
    → query embedding 自动生成
    → this._backend.read(backendQuery, mode)  ← 委托 @cortex/memory
    → 30天 TTL 过滤
    → content_blob 关键词过滤
    → 混合检索增强（BM25 + 向量融合）
    → 权重自然老化
    → 排序 + 截取

memory-store.MemoryStore.cas(memoryId, expected, newState)
    → MEMORY_VALID_TRANSITIONS 校验  ← 单一事实来源
    → this._backend.cas(memoryId, expected, newState)  ← 委托 @cortex/memory
```

## 五、星盘结论

| 维度 | 评级 | 证据 |
|------|------|------|
| **类型定义一致性** | ✅ **一致** | 三层共用同一套 `MemoryEntry`/`MemoryWriteInput`/`MemoryQuery`/`MemoryKind`/`SemanticState` 类型（来自 `@cortex/shared`），无独立复刻 |
| **接口继承关系** | ✅ **正确** | `@cortex/memory` 的 `IMemoryStore extends SharedIMemoryStore`，非平行定义 |
| **方法签名对齐** | ✅ **对齐** | 适配层 27 个方法全部委托到存储层，签名一致 |
| **状态机契约** | ✅ **单一来源** | `MEMORY_VALID_TRANSITIONS` 在 shared 定义，存储层和适配层均引用同一常量 |
| **常量依赖链** | ✅ **单向无环** | `config → schema.ts → memory-store.ts`，无反向依赖 |
| **Barrel 导出** | ✅ **完整** | 三层 index.ts 均导出全部公开符号 |
| **适配层扩展** | ✅ **合法叠加** | 适配层在委托基础上增加 embedding/SHA256/BM25/权重老化——不破坏基类契约 |

> **三层记忆契约一致且完整。**
